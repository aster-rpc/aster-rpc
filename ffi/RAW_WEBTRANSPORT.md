# Raw WebTransport ABI 4.17

Standalone raw WebTransport is independent of Iroh/RPC framing. A listener binds TCP and QUIC with caller-supplied PEM material and an exact unnormalized route. `start` uses foreign authentication upcall kind80 before upgrade; `start_public` explicitly permits unauthenticated access. Application protocols remain responsible for their own claim/PoP handshake before admitting media. Each input span is capped at 16 MiB before reading/copying (listener config spans: 64 KiB). Writes also obey configured max_read_bytes. Inputs are copied during the call; all span arguments are C structs **by value**, including on Java FFM.

The 104-byte, 8-aligned config requires exact struct_size and zero flags/reserved. Zero limits select adapter defaults. Limits bound admitted sessions, live stream handles, queued datagrams, datagram payload, read allocation, and foreign auth. Runtime max_inflight_operations independently bounds pending async tasks; overflow returns OPERATION_LIMIT synchronously.

Handles are runtime-local owned values, never Iroh handles. Listener stop removes its owner and joins within the grace budget; zero grace is immediate. Session close actively closes QUIC but retains the handle for close info/stats; session free closes and removes it. Stream free removes the owner and wakes blocked operations. FIN retains the send owner for transport ACK or explicit reset. Direction flags are send bit0, receive bit1; unidirectional operations on the wrong direction fail.

Async submission returns an operation ID. Every future selects native operation cancellation and runtime shutdown, including accept, stream credit, read, write and ACK waits. Cancellation drops the future and publishes the standard terminal cancellation event. Writes may have delivered a prefix when cancelled; never automatically replay. If handle completion loses cancellation, its unseen handle is closed and removed. A completion that already won cancellation is owned by the host and must be collected/freed normally.

Events: 121 SESSION owns event.handle; 122 STREAM owns event.handle and direction flags; 123 READ carries raw bytes with EOF bit0; 124 DATAGRAM carries exactly one raw datagram (empty is valid); 125 CLOSED carries version1 JSON kind/code/reason; 126 ACKED has boolean flags (true means transport acknowledgement, false means reset/loss). UNIT_RESULT completes writes/FIN/reset/stop/priority setters. Priority getter uses BYTES_RESULT, Some bit0 and signed i32 little-endian payload; None has no bytes. Higher signed priorities are served first. Every nonzero event.buffer must be released, including empty payloads.

Synchronous listener_addr, session_info, session_stats and stream_info return owned UTF-8 version1 JSON spans; release with aster_string_release. Stream JSON includes stream_id and directions. Session JSON includes stable connection_id/session_id, current peer_address and closed. Stats include RTT microseconds, cwnd bytes, MTU, sent/lost packets, lost bytes, congestion events, UDP TX/RX bytes/packets, PING TX and ACK RX counters. max_datagram_size returns explicit is_some; unsupported is not a zero-size datagram limit. Oversized datagrams fail without truncation. Listener start/stop must run off Tokio worker threads.
